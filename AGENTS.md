## Команды
На Windows нет `make` и нет Docker: команды через `make.ps1` / `scripts/dev.py` (единый реестр, контрактный тест `test_dev_cli_contract`). Реальная проверка контейнеров — только в CI (`compose-smoke`). Локально: `ruff format --check`, `ruff check`, `mypy .` (`--strict`), `pytest -m "not live_api and not e2e"`, `pytest --cov` (порог 80%).
